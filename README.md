# AI Catchup 第1回

発表、作ったもの、活用事例、試して分かったこと、まだ分からないことを持ち寄る公開アーカイブです。

開催日：2026年10月3日（土）19:00〜21:00 JST。開催案内は [Codex Catchup #1](https://luma.com/39cmcrue) を参照してください。

OpenAI DevDayをきっかけに、日本で集まり、発表を見て、話し、試して理解する初回を開催しました。[主催者の振り返りと感謝](RETROSPECTIVE.md) を残しています。

共有ハッシュタグ：**#AICatchup**

## 見る・持ち寄る

- [寄せられた資料・活用事例](contributions/)
- [資料・活用事例を投稿する](https://github.com/AICatchup/catchup-001/issues/new?template=share.yml) — URLと一言からどうぞ。GitHubアカウントが必要です。
- [PRで投稿する](https://github.com/AICatchup/community/blob/main/CONTRIBUTING.md) — Markdownや元資料へのリンクを追加できます。
- [投稿の受付・確認状況](https://github.com/AICatchup/catchup-001/issues?q=is%3Aissue+label%3Asubmission)
- [訂正・リンク切れ・質問](https://github.com/AICatchup/catchup-001/issues/new?template=correction.yml)

発表していない人も、開催後の投稿も歓迎します。投稿は任意です。

## 共通のビジョンと方針

[ビジョン](https://github.com/AICatchup/community/blob/main/VISION.md) / [判断・問題への対応](https://github.com/AICatchup/community/blob/main/POLICY.md) / [投稿方法](https://github.com/AICatchup/community/blob/main/CONTRIBUTING.md)

共通方針の正本は [community](https://github.com/AICatchup/community) にあります。この回には資料と記録を蓄積し、方針のコピーは置きません。全体の目的は、人とのつながりと知見を通して、一人ひとりが「自分にも、もっとできる」と感じられることです。
